# Lab04 - Algoritmos y Estructuras de Datos

Este repositorio contiene el desarrollo del laboratorio 04 del curso de Desarrollo de Software.

Incluye el uso de Git (commits, ramas, conflictos) y estructuras de grafos en Python (DFS, BFS, rutas con Dijkstra).

## Procesos realizados

- Se creó el repositorio remoto en GitHub y se subió el proyecto.
